Unity3D Engine Basics: Core Concepts

Unity is a cross-platform game engine. A project is organized into Scenes, which contain GameObjects. Everything in a Scene, such as characters, lights, cameras, and UI elements, is a GameObject.

A GameObject is an empty container until Components are attached to it. Every GameObject has a Transform component that stores its position, rotation, and scale.

Components add behavior and data to a GameObject. Common built-in components include Renderer, Collider, Rigidbody, Camera, Light, and AudioSource.

A Prefab is a reusable GameObject template stored as an asset. Changes made to the Prefab asset propagate to all of its instances in Scenes, while instances can still hold per-instance overrides.

Scripting with MonoBehaviour

Unity scripts are written in C# and usually derive from MonoBehaviour, which lets them be attached to GameObjects as components.

Awake is called once when the script instance is loaded. Start is called before the first frame update, only if the script is enabled. Update is called once per frame, and FixedUpdate is called at a fixed time interval and is the right place for physics code.

Public fields and fields marked with [SerializeField] are exposed in the Inspector, so values can be edited without changing code. Time.deltaTime gives the time in seconds since the last frame and is used to make movement frame-rate independent.

Physics and Rendering

A Rigidbody component places a GameObject under the control of the physics engine so it responds to gravity and forces. A Collider defines the shape used for collision detection; marking it as a Trigger raises OnTriggerEnter events instead of causing physical collisions.

Materials define how a surface looks, and Shaders are the programs that compute that appearance. Unity provides the Built-in Render Pipeline, the Universal Render Pipeline (URP), and the High Definition Render Pipeline (HDRP).

Assets and Build

Assets such as textures, models, audio clips, and scripts live in the Assets folder of the project. The Package Manager installs additional features, and the Build Settings window selects the target platform, such as Windows, macOS, Android, iOS, or WebGL.
